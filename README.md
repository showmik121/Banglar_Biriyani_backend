# Banglar Biriyani — Backend API

Hono + Supabase PostgreSQL + Drizzle ORM. Serves the menu, login/sign-up, orders and the admin panel
for the [frontend](https://github.com/showmik121/Banglar_Biriyani_frontend).
Every endpoint, its rules and error codes are listed in [API.md](API.md).

## প্রথমবার চালানো

1. `.env.example` ফাইলটা কপি করে নাম দিন `.env`, তারপর ভেতরে আপনার Neon `DATABASE_URL` আর একটা লম্বা `JWT_SECRET` বসান।
2. টেবিল তৈরি ও নমুনা মেনু:
   ```bash
   npm install
   npm run db:push
   npm run db:seed
   ```
3. সার্ভার চালু: `npm run dev` (অথবা `run-backend.bat`-এ ডাবল-ক্লিক)। API চলবে http://localhost:3001-এ।

`.env` কখনো GitHub-এ যাবে না, `.gitignore` সেটা আটকে রাখে।

## GitHub Actions (CI)

প্রতিটা push-এ `.github/workflows/ci.yml` চলে:

1. **Type check & unit tests**: সবসময় চলে।
2. **Integration tests**: শুধু তখনই চলে যখন GitHub-এ `TEST_DATABASE_URL` secret দেওয়া থাকে।
   Neon-এ একটা আলাদা *test branch* বানিয়ে তার connection string দিন, আসল ডাটাবেস নয়,
   কারণ এই টেস্ট ডাটাবেসের ডেটা মুছে নতুন করে বসায়।
   Repository → Settings → Secrets and variables → Actions → New repository secret → নাম `TEST_DATABASE_URL`।

## Admin panel

Open `/admin` on the website and sign in with the admin account (`admin@banglarbiriyani.com`).
The admin does everything; there is no separate kitchen staff account.

| পাতা | কী করা যায় |
| --- | --- |
| Orders | আজ / এই মাস / সব মিলিয়ে বিক্রি ও অর্ডার সংখ্যা, অর্ডার দেখা, এক ক্লিকে পরের ধাপ (Confirm → Cooking → On the way → Delivered), bKash/Nagad পেমেন্ট নিশ্চিত করা, অর্ডার বাতিল |
| Menu | খাবার যোগ, ছবি (লিংক), নাম, দাম বদলানো, মেনুতে দেখানো/লুকানো |
| Offers | প্রোমো কোড (যেমন DIU10), % বা ৳ ছাড়, সর্বনিম্ন অর্ডার, শেষ তারিখ |
| Delivery points | ডেলিভারি এলাকা আর সময় (ডেলিভারি ফ্রি) |

নিরাপত্তা: পাসওয়ার্ড bcrypt দিয়ে hash করা, login session HttpOnly cookie-তে, ৫ বার ভুল পাসওয়ার্ডে ১৫ মিনিট বন্ধ,
প্রতিটা admin API-তে role যাচাই, আর প্রতিটা পরিবর্তন `audit_logs` টেবিলে লেখা থাকে।
দাম আর ছাড় সবসময় server-এ হিসাব হয় (ডেলিভারি ফ্রি), browser থেকে বদলানো যায় না।

### নতুন টেবিল যোগ করা (একবার)

এই আপডেটে `offers` আর `delivery_zones` টেবিল যোগ হয়েছে। ডাটাবেসে বসাতে:

```bash
npm run db:push
```

নমুনা ডেলিভারি পয়েন্ট আর DIU10 অফারসহ সব নতুন করে বসাতে চাইলে (পুরোনো ডেটা মুছে যাবে):

```bash
npm run db:seed
```

Live-এ যাওয়ার আগে `.env`-এ `SEED_ADMIN_PASSWORD` দিয়ে শক্ত admin পাসওয়ার্ড সেট করুন।

## Hosting on Supabase (Edge Functions)

The API runs as one Supabase Edge Function named `api`. The database stays on Neon.

**Automatic:** every push to `main` runs the tests and, when they pass, deploys the API to
Supabase (the `deploy` job in `.github/workflows/ci.yml`). It needs the repository secret
`SUPABASE_ACCESS_TOKEN` (a Supabase access token scoped to Edge Functions of this project).
`deploy-supabase.bat` still works for a manual deploy.

**First-time / manual setup:**

1. Create a free project at supabase.com and copy its **Project ID** (Project Settings → General).
2. Double-click `deploy-supabase.bat`. It builds the API (`node edge/build.mjs`), signs you in,
   copies the secrets from `.env` to Supabase, sets `NODE_ENV=production`, and deploys.
3. The script also writes the frontend's `public/_redirects` so Netlify sends `/api/*` to
   `https://<project-id>.supabase.co/functions/v1/api/...`. Push the frontend afterwards.

How it fits together:
- `server/app.ts` is the API. `server/index.ts` runs it on Node for local development;
  `supabase/functions/api/index.ts` runs the same app on Deno.
- `supabase/functions/api/app.bundle.js` is generated by the build and is not committed.
- CI builds the bundle and runs it in Deno on every push (`edge/smoke-test.mjs`).
- Login rate limiting is kept in memory per function instance, so it is weaker on Supabase
  than on a single always-on server.

## অর্ডার আপডেট ইমেইল (Brevo, ফ্রি — দিনে ৩০০টা)

যে কাস্টমার সাইন-ইন করে অর্ডার দেন, তিনি ইমেইল পান: অর্ডার পাওয়া গেছে, Confirmed, On the way, Delivered, Cancelled।

1. brevo.com-এ ফ্রি অ্যাকাউন্ট খুলুন।
2. Senders, Domains & Dedicated IPs → Senders → আপনার Gmail যোগ করে verify করুন।
3. SMTP & API → API Keys → নতুন key বানান।
4. Supabase → Edge Functions → Secrets-এ দুটো secret যোগ করুন:
   - `BREVO_API_KEY` = Brevo-র key
   - `EMAIL_FROM` = verify করা Gmail ঠিকানা
5. ব্যস। নতুন deploy লাগবে না; secret সেভ হলেই কাজ শুরু।

**নতুন অর্ডারের খবর রেস্তোরাঁর ফোনে (ঐচ্ছিক):** একই জায়গায় আরেকটা secret যোগ করুন: `OWNER_NOTIFY_EMAIL` = রেস্তোরাঁর Gmail ঠিকানা (একাধিক হলে কমা দিয়ে)। তখন প্রতিটি নতুন অর্ডারে ওই ইনবক্সে "🔔 নতুন অর্ডার" ইমেইল যাবে, ফোনের Gmail অ্যাপ নোটিফিকেশন দেখাবে। অ্যাডমিন পেজ বন্ধ থাকলেও কাজ করে।

**ফোনে পুশ নোটিফিকেশন (ঐচ্ছিক, ইমেইল ছাড়াই):** অ্যাপ বা অ্যাডমিন পেজ বন্ধ থাকলেও নতুন অর্ডারে ফোন বাজবে।
1. `update-database.bat` চালান (নতুন টেবিল `push_subscriptions` তৈরি হবে)।
2. `make-push-keys.bat` চালান (একবারই; `.env`-এ VAPID_PUBLIC_KEY ও VAPID_PRIVATE_KEY যোগ হবে)।
3. `deploy-supabase.bat` চালান (key দুটো Supabase-এ যাবে)।
4. ফোনে অ্যাডমিন পেজ খুলে Orders ট্যাবের "ফোনে নোটিফিকেশন চালু করুন" বাটন চাপুন, তারপর "টেস্ট পাঠান"।
Firebase লাগে না: Chrome ভেতরে Google-এর FCM দিয়েই পাঠায়। iPhone-এ আগে Safari-র Share → Add to Home Screen করে সেখান থেকে অ্যাডমিন খুলতে হবে (iOS 16.4+)।

**Google দিয়ে সাইন ইন (ঐচ্ছিক):**
1. console.cloud.google.com → একটা প্রজেক্ট → APIs & Services → OAuth consent screen (External; নাম, ইমেইল দিন; Publish করুন)।
2. Credentials → Create credentials → OAuth client ID → Application type: **Web application**।
3. "Authorized JavaScript origins"-এ সাইটের ঠিকানা দিন (যেমন `https://banglarbiriyani.netlify.app`, নিজের ডোমেইন কিনলে সেটাও `https://` সহ)। Redirect URI লাগে না।
4. যে Client ID পাবেন (শেষে `.apps.googleusercontent.com`) তা `.env`-এ `GOOGLE_CLIENT_ID=` এর পরে বসিয়ে `deploy-supabase.bat` চালান। Client ID গোপন নয়, কিন্তু Client secret এখানে লাগে না।
5. `update-database.bat` একবার চালান (users টেবিলে google_sub যোগ হয়)।
নিরাপত্তা: Google অ্যাকাউন্ট আইডি (sub) দিয়ে মেলানো হয়। একই ইমেইলে আগে পাসওয়ার্ড-অ্যাকাউন্ট থাকলে Google দিয়ে ঢোকানো হয় না (পাসওয়ার্ড দিয়ে ঢুকতে বলা হয়)। স্টাফ ও অ্যাডমিন কখনো Google দিয়ে ঢুকতে পারে না।

key কখনো git-এ বা চ্যাটে দেবেন না। secret না থাকলে ইমেইল চুপচাপ বন্ধ থাকে, অর্ডারে কোনো সমস্যা হয় না।
